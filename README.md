# e-LGU: Local Government Service Management and Online Request System

A web-based system built with **Next.js** that lets citizens submit government service
requests online and helps LGU employees manage, monitor, and process requests in one
centralized system.

This repository is also an **IS project portfolio** — it includes an interactive
Project Schedule Plan with a Work Breakdown Structure, Activity Sequencing,
Activity Duration Estimation, and a 12-week Gantt Chart.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Deploy

This project is configured to deploy on Vercel. After pushing to GitHub:

1. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New → Project** and import this repository.
3. Vercel auto-detects **Next.js** — click **Deploy**.

## Views

- `1 · Citizen Landing` — public service showcase and request tracking
- `2 · Citizen Dashboard` — example citizen account and request statuses
- `3 · Admin Dashboard` — LGU internal dashboard with analytics
- `4 · Project Plan` — project portfolio: overview, WBS, sequencing, durations, Gantt chart, budget, team roles, organizational chart, and project communication plan

## Tech Stack

- Next.js (App Router), React, TypeScript
- Tailwind CSS, shadcn/ui
- Lucide icons, Recharts
